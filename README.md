# CRM Alana Tours

Sistema interno de gestion de clientes para Alana Tours.

## Caracteristicas

### 1. Gestion de Agencias
- **CRUD completo**: Crear, editar, eliminar agencias y sus sucursales.
- **Historial de actividad**: Registro de todas las acciones (creacion, edicion, notas, importaciones).

### 2. Vista de Agencias Mejorada
- Diseño responsive adaptado a dispositivos moviles y escritorio.
- Dashboard con resumen visual de metricas clave.

### 3. Importacion Masiva
- Carga de archivos CSV y XLSX.
- Deteccion de duplicados.
- Validacion con Zod.
- Generacion de plantillas descargables.

## Stack Tecnologico
- **Frontend**: Next.js 15+ (App Router), TypeScript, Tailwind CSS, Framer Motion.
- **Backend/Base de Datos**: Google Cloud SQL (PostgreSQL).
- **Infraestructura**: Google Cloud Run, GitHub Actions (CI/CD).

## Proximos Pasos (Post-MVP)
- Reportes exportables en PDF/Excel.
- Dashboard con graficas de rendimiento mensual.
- Sistema de notificaciones en tiempo real.
