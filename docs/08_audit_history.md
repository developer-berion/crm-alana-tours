\# Audit History



\## What Is Logged

\- Create branch

\- Update any field

\- Change status

\- Change temperature

\- Change relationship

\- Add note

\- Bulk import create

\- Password reset



\## What Is Not Logged

\- Views

\- Reads

\- Navigation



\## UI

\- Show last 5 actions per branch

\- Human-readable messages

\- Timestamp relative (e.g. “2 hours ago”)



\## Permissions

\- All users can read

\- No user can edit or delete logs
