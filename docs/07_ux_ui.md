\# UX / UI Guidelines



\## Brand

\- Primary: #006AB3

\- Accent: #D7932C

\- Background: #F8F9FA

\- Success: #28A745

\- Warning: #F7CE72

\- Error: #D93025



\## Typography

\- Font: Nohemi

\- Headings: Bold / SemiBold

\- Body: Regular



\## Layout

\- Desktop: Sidebar + main content

\- Mobile: Header + cards



\## Components

\- Tables (desktop)

\- Cards (mobile)

\- Status badges

\- Activity feed



\## Animations

\- Hover transitions

\- Fade-in

\- 200–300ms duration

\- No heavy motion
