\# Bulk Import – CSV / Excel



\## Supported Formats

\- .csv

\- .xlsx



\## Required Fields

\- Agency name

\- Email



\## Optional Fields

\- Branch name

\- Contact name

\- Phone

\- Country

\- State

\- City

\- Instagram

\- TikTok

\- Website

\- Contact status

\- Temperature

\- Relationship

\- Initial note



\## Import Flow

1\. Upload file

2\. Parse and normalize data

3\. Validate required fields

4\. Detect possible duplicates

5\. Show preview:

&nbsp;  - Valid

&nbsp;  - Duplicated

&nbsp;  - Invalid

6\. Import only valid records



\## Duplicate Detection Criteria

\- Same agency name

\- Same email

\- Same country + city (if available)



\## Duplicate Handling (MVP)

\- Show duplicates grouped

\- Do not auto-import

\- Inform user only
